# Catálogo de ubicaciones

Fuente: https://github.com/RitchieRD/ubigeos-peru-data
Archivos originales de la carpeta `json` de la rama `main`, descargados el 22 de octubre de 2026. Se conserva la licencia en `UBIGEO-LICENSE.txt`.

La copia contiene 25 departamentos, 196 provincias y 1892 distritos. Se comprobaron las relaciones entre identificadores de los tres niveles. Es un catálogo comunitario; no se afirma certificación oficial ni verificación exhaustiva de vigencia de cada distrito.

El formulario conserva los nombres de los datos y utiliza los identificadores únicamente para filtrar opciones. La carga ocurre desde el propio sitio, sin consultas a GitHub durante el uso del formulario.
