# Trabaja con nosotros

El formulario admite datos de contacto, área, experiencia, consentimiento y CV en PDF de hasta 5 MB. Envía a empleos/enviar.php mediante multipart/form-data.

Usa el mismo .env de la raíz y MAIL_TO que Contacto. Se retiró la configuración independiente y la dependencia phpdotenv. No crear otro .env en esta carpeta.

Instrucciones vigentes de instalación y verificación: [CONFIGURACION-ENVIOS.md](../CONFIGURACION-ENVIOS.md).
